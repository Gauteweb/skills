# AI skills
In my work I use Mistral Vibe for personal projects and Claude Code for professional projects. 

In this repo you will find different AI skills I create for both Mistral and Claude.

I name them [AIservice_skillname_SKILL.md]. Most skills will work either vendor, but to use them, you need to rename them and upload according to the AI service instructions.

Or you can most likely just copy the markdown text to your chat and ask your AI service to make it a skill.
